# v0.1.0-beta.4 release validation

Target: Waveshare ESP32-C6-Touch-LCD-1.9
ESP-IDF: v6.1

## Release gates

The beta.4 candidate is only eligible for release after the repository QA workflow passes all of these jobs on the same candidate commit:

- qa-regressions
- host-a
- host-b
- host-c
- build-default
- build-all-benches

The default firmware build also produces the merged 0x0 flash image and pinned recognition database used for QA.

## Compile fixes made during release validation

- Replaced four embedded NUL bytes in `firmware/components/web_mgmt/web_mgmt.c` with normal C `\0` character literals so GCC 15 with `-Werror` accepts the source without changing runtime behavior.
- Updated the Agent D web bench after the SoftAP status API stopped exposing the AP password. The bench now logs the SSID and IP while rendering the password as `***`; it does not restore password exposure.

## SD validation scope

- Non-destructive SD write/read verification is available in the Agent D SD I/O bench.
- Whole-card formatting is exposed only through the separately gated destructive SD bench / explicitly authorized management flow; it is not silently performed by the normal non-destructive test.
